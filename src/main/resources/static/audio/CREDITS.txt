Schmoll Crossword: recorded sounds and music
=============================================

Every recorded file in this folder is in the public domain (Creative Commons Zero, CC0 1.0):
https://creativecommons.org/publicdomain/zero/1.0/
CC0 needs no credit, but the authors are thanked here anyway. Each track's own page on OpenGameArt.org lists it as
CC0 (checked one by one). For this game the songs were converted to MP3, given the same gentle mastering (a little
more low end and air, a wider stereo image, a hall reverb, even loudness), and each song's file was cut so that it
starts with a build-up into the song, then loops a section seamlessly (loop points in music/songs.json).

Sound effects (audio/sfx) - Kenney (www.kenney.nl), CC0

Boss music (audio/music). Each boss has a song per phase: <world>.mp3 is phase 1, <world>-p2.mp3 phase 2 and so on
(the first five bosses have one phase, the last three 3, the Void 5). Each file starts with a 6.5 s build-up made
from the song's own lead-in (played during the boss's intro), then the song loops seamlessly.
